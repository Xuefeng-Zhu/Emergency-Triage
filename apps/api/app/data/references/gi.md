# Local reference: chest pain with GI features (gi)

> Illustrative demo scaffolding for the triage workstation. Not a validated
> clinical protocol. The nurse and treating clinician remain the decision-makers.

§1 Burning, meal-related chest discomfort with antacid response suggests a
reflux pattern; cardiac causes should still be considered in patients with
risk factors, because relief by antacids does not exclude ischemia.

§2 A 12-lead ECG (ECG-12) is a low-burden test that keeps the cardiac
differential covered while a GI pattern is explored.

§3 High-sensitivity troponin I (LAB-TROP-HS) is reasonable when any cardiac
risk factors coexist with a GI-pattern presentation.

§4 A complete blood count (LAB-CBC) screens for anemia when GI blood loss is
possible.
